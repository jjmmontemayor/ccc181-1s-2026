## Git Exercises

Complete the Git exercises available at [Git Exercises](https://gitexercises.fracz.com/).

## Instructions

1. Open the exercise website and complete the required Git exercises.
2. Before starting, configure your Git identity using your **ID number without the hyphen**:

   ```bash
   git config --global user.name "YOUR_ID_NUMBER"
   git config --global user.email "YOUR_ID_NUMBER@ccc181.local"
   ```

   Replace `YOUR_ID_NUMBER` with your actual student ID number, excluding any hyphen.

   **Example:** If your ID number is `2023-12345`, use:

   ```bash
   git config --global user.name "202312345"
   git config --global user.email "202312345@ccc181.local"
   ```

3. Complete the exercises on the website.
4. Take a screenshot showing your progress or completed exercises. Ensure that your Git configuration name or your completed-task progress is visible in the screenshot.


## Submission

Submit your work through your personal **CCC181 GitHub repository**.

### Repository Folder

Inside your CCC181 repository, create the following folder:

```text
activities/git-exercises/
```

Upload all required screenshots to this folder.

### Requirements

- Complete the assigned exercises at [Git Exercises](https://gitexercises.fracz.com/).
- Use your **student ID number without the hyphen** when configuring Git.
- Submit a **separate screenshot for each completed exercise**.
- Each screenshot must clearly show:
  - Your face
  - The completed exercise or progress for that specific exercise
  - Your Git configuration name or other visible identifying details, when applicable

### Screenshot Filename Format

Use the following filename format:

```text
<lastname>_<firstname>_<exercise-number>.<jpg, png, gif>
```

**Example:**

```text
delaCruz_Juan_01.png
delaCruz_Juan_02.png
delaCruz_Juan_03.png
```

Only `.jpg`, `.png`, or `.gif` image files are accepted.

### Final Submission

Commit and push all screenshots to your GitHub repository. Submit the **URL of your CCC181 GitHub repository** through MOLE.
