For a single developer building for both Android and iOS in a few weeks, Flutter's single codebase is decisive. 05

Students who know Python and JavaScript pick up Dart quickly. Types can be written or inferred with var. final means the variable cannot be reassigned; const means the value is known at compile time, which Flutter uses to avoid rebuilding widgets. Null safety is the big difference from JavaScript: a type without a question mark can never be null, and the compiler forces you to handle the nullable ones with ?., ?? or a check. String interpolation uses $name or ${expression}. DartPad at dartpad.dev runs Dart in the browser for quick practice.

Use the theme

textTheme.displayLarge, not a hard-coded font size, so text scaling works.

CCC181 · Week 8 · Flutter and Dart foundations

10

A stateless widget is like a Jinja partial or a pure function: given position and minutes, it always draws the same card. The build method returns the widget subtree. Reading styles from Theme.of(context) keeps the app consistent and respects the user's system text size, an accessibility point from Week 3. Marking constant subtrees with const lets Flutter skip rebuilding them. Most widgets in an app should be stateless.

11

A stateful widget has two classes: the widget, which is immutable configuration, and its State object, which persists across rebuilds and holds changing data. Calling setState marks the widget dirty, and Flutter rebuilds it on the next frame. The underscore makes a name private to its file. This kind of local, short-lived UI state, such as a toggle, a tab index or a text field, belongs in a StatefulWidget. Data that several screens share, such as the current ticket, needs the state management approaches of Week 9.

If students know CSS flexbox from Week 3, Column and Row are flex containers with a main axis and a cross axis, and Expanded is flex: 1. SizedBox is the cleanest way to add a gap between children. Navigator manages a stack of routes, exactly like the browser history: push opens a new screen with a slide animation and the system back gesture pops it. Class discussion

Questions to discuss

Q1

What is the difference between a StatelessWidget and a StatefulWidget?

Q2

Why does localhost not reach Flask from the Android emulator?

Q3

A ListView inside a Column throws an error. Why, and how do you fix it?

Q4

The form validates in Flutter. Why must the Flask API validate again?

CCC181 · Week 8 · Flutter and Dart foundations

24

Expected answers. Q1: a stateless widget is drawn only from its constructor inputs; a stateful widget has a State object that keeps data across rebuilds and calls setState to redraw when it changes. Q2: the emulator is its own virtual device, so localhost means the emulator itself; the host machine is reachable at 10.0.2.2. Q3: a Column gives its children unlimited height, and a ListView tries to be as tall as possible, so its height is undefined; wrapping it in Expanded gives it the remaining space. Q4: the API can be called by any client or tool, and a modified app can skip client checks, so only server validation protects the data, as in Weeks 3, 4 and 6.
